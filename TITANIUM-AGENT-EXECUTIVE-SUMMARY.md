## Critical Success Factors

### 1. Single Manager

**One Titanium Manager coordinates everything.**

❌ Two managers = confusion, duplicates, conflicts  
✅ One manager = clear authority, traceable work

---

### 2. Consolidated SEO

**One SEO Architecture Agent handles all technical SEO.**

❌ Three separate SEO agents = overlap, redundancy, confusion  
✅ One expanded agent = faster, cheaper, clearer

---

### 3. Publishing/QA is Mandatory Gate ⭐

**Nothing becomes public without passing Publishing & QA.**

This agent checks:
- Accuracy
- Links work
- Tracking parameters
- Mobile presentation
- Metadata complete
- Schema valid
- Consent language
- Approval obtained

**This is the professional quality control gate.**

---

### 4. Structured Handoffs

**Agents return YAML, not prose paragraphs.**

```yaml
task_id: task_001
agent: seo-architecture
status: completed
summary: Optimized article for SEO
deliverables: [metadata.yaml, schema.json, links.csv]
confidence: high
approval_required: true
recommended_next_agent: publishing-quality-control
```

**Traceable, parsable, clear.**

---

### 5. Return to Manager After Each Stage

**Specialists don't chain to other specialists.**

❌ Scout → Strategist → SEO → QA (uncontrolled chain)  
✅ Scout → Manager → Strategist → Manager → SEO → Manager → QA

**Manager controls flow, prevents loops.**

---

### 6. Memory Governance

**Shared:** Brand guidelines, policies  
**Agent-specific:** Procedures, tools  
**Live queries:** Changing state (rankings, consent, purchases)

**Don't cache what should be retrieved.**

---

### 7. Incremental Growth

**Start with 7 (content), grow to 11 (complete) when ready.**

Don't add agents just to increase count.  
Add only when workload, tools, or permissions require it.
