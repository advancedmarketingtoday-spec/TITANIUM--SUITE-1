# Corona Shoutouts

**Local newsletter and community resource for Corona, California**

---

## Overview

Corona Shoutouts is a hyperlocal newsletter and website serving the Corona, CA community with:
- Weekly newsletter
- Business directory
- Event calendar
- Local news and stories
- Community hotspots guides
- Sports coverage

**Website:** coronashoutouts.com  
**Platform:** Letterman.ai  
**Status:** Live with full navigation
